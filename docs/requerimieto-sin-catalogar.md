Requisitos sin catalogar
1. La aplicacion en general debe ser multiplaforma para escritorio debe funcionar correctamente en windows, linux, y mac 
2. El sistema deberá permitir que al menos el 80 % de los usuarios participantes completen las tareas básicas de creación, edición, guardado y exportación de un documento sin asistencia.
3. El sistema deberá permitir al usuario seleccionar entre edición mediante código LaTeX, componentes o controles visuales, o una combinación de ambos mediante un enfoque híbrido.
4. El sistema deberá actualizar la vista previa como máximo 200ms después de una modificación.
5. El sistema deberá permitir al usuario crear y editar texto, secciones, imágenes, tablas, ecuaciones, Bibliografía, Referencias, Índices, Figuras, Notas al pie, Código fuente utilizando elementos compatibles con LaTeX.
6. El sistema deberá permitir crear, editar, visualizar, compilar y almacenar documentos localmente sin requerir conexión a Internet.
7. EL sistema debe permitir crear editar y visualizar y guardar documentos
8. El sistema debera integrarse bien con github para realizar control de versiones como commit push y pull y tener una sincronizacion de los documentos con respositorios
9. El sistema debera permitir escenarios de colaboracion entre usuarios
10. El sistema deberá informar al usuario cuando ocurra un error durante la compilación del documento e indicar la ubicación del error cuando esta información esté disponible.
11. El sistema deberá permitir abrir documentos LaTeX existentes.

12. El sistema deberá permitir exportar los documentos a PDF.

13. El sistema deberá generar y conservar el código fuente en formato LaTeX estándar.
